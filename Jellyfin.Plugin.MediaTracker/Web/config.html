Import from MediaTracker server to Jellyfin

Control how watch history from MediaTracker server is brought into Jellyfin.

Check this to prevent Jellyfin from marking an item as 'watched', even if it is marked watched on MediaTracker server. This protects your local watch history.
Check this to prevent Jellyfin from marking an item as 'unwatched', even if it is marked unwatched on MediaTracker server.
Check this to prevent Jellyfin from syncing in-progress playback status from MediaTracker server (e.g., "50% watched").

Sync from Jellyfin to MediaTracker server

Control how your Jellyfin viewing activity is sent to your MediaTracker server account.

Instant Sync (As it happens)

Tells MediaTracker server what you're watching in real-time. Recommended to be enabled for most users.
When you watch something on Jellyfin, immediately update it on MediaTracker server.
When you manually mark something as unwatched in Jellyfin, immediately update it on MediaTracker server.
